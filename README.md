## 🎮 About the Game

Ultrapool is a colorful single-player pool roguelike deckbuilder developed by Icedrop Games and published by offbrand games. It released on August 24, 2026, for PC, iOS, and Android. Players pocket unusual balls, build score, earn money, and survive ten rounds of increasingly difficult pool challenges.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Ultrapool**. This trainer provides optional control over Ultrapool's scoring, bar currency, ball upgrades, round progression, and shot assistance. It is designed around the game's pool-table runs, ball abilities, fusion system, snacks, cubes, and ten-round structure.

**Target Audience:** Players who want to experiment with unusual ball combinations, test fusion builds, practice trickshots, explore snacks and cubes, or make single-player runs more accessible.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Score** — Prevents the current run score from decreasing and helps maintain high scoring chains while pocketing balls.
- **Unlimited Bar Money** — Keeps bar currency available for purchasing and improving balls between rounds.
- **Unlimited Snacks and Cubes** — Prevents supported snacks and cubes from being consumed during a run.
- **Shot Assistance** — Adds optional aiming and power assistance for more consistent trickshots.

### 🧰 Inventory

- **Max Ball Upgrades** — Applies the highest available upgrade value to supported balls in the current run.
- **Ball Fusion Control** — Preserves required resources when combining two balls at the cocktail bar.

### 🌍 World

- **Round Control** — Freezes or advances the current round counter, making it easier to test builds across the ten-round run.

### ⚔️ Combat

- **No Combat Mode** — Ultrapool has no combat system. This entry is reserved for trainer compatibility and remains inactive during normal pool gameplay.

## 📖 Detailed Feature Guide

### Movement & Exploration

Ultrapool is played from a top-down pool-table view rather than through character movement. Aim the cue, adjust shot strength, and release the shot to send balls around the table. Use Shot Assistance only when you want help lining up difficult angles.

### Tools & Inventory

Your run setup consists primarily of balls and their effects, with additional modifiers supplied by snacks and cubes. Spend bar money between rounds to acquire or improve balls, and use Ball Fusion Control when testing combinations at the cocktail bar.

### World & Environment

Each run is structured around ten rounds. Pocketing balls generates score, and strong scores provide money for future purchases and upgrades. Round Control can pause progression while you inspect a build or advance a test run quickly.

### Combat & Weapons

Ultrapool does not contain combat. Progress is determined by pocketing balls, extending their special effects, building score, and meeting the requirements of each pool round.
